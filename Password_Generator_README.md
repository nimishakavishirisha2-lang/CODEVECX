# Password Generator & Strength Checker

## Project Description
This is a Python-based application that generates random passwords and checks password strength. It helps users create strong passwords using different character types.

## Features
- Generate random passwords
- Customize password length
- Include uppercase and lowercase letters
- Include numbers and special symbols
- Check password strength
- Validate password requirements
- Generate multiple passwords
- View passwords generated during the current session
- Menu-driven interface with input validation

## Technologies Used
- Python
- `string` module
- `secrets` module

## How to Run
1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command in the terminal:

```bash
python password_generator.py
```

## Usage
Choose an option from the menu to generate a password, check password strength, generate multiple passwords, or view session history.

## Security Note
The application does not save passwords to a file. Passwords generated during a session are stored temporarily in memory.
