# File Handling & Data Processing System

## Project Description
This is a Python console-based application that manages student records using file handling and CSV data processing. It allows users to add, view, and search records and analyze student data.

## Features
- Add student records
- View all student records
- Search students using Student ID
- Calculate total number of students
- Calculate average marks
- Find highest and lowest marks
- Calculate average age
- Count name frequency
- Store records in a CSV file
- Validate user input and handle errors

## Technologies Used
- Python
- CSV module
- OS module
- Collections module

## Files Used
- `file_data_processor.py` — Main Python program
- `student_data.csv` — Automatically created file for storing student records

## How to Run
1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal and run:

```bash
python file_data_processor.py
```

## How to Use
Select an option from the menu to add records, view records, search for a student, or generate a data summary.
