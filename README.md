## Student Management System

### Project Description
This is a Python console-based application used to manage student records. It uses SQLite database to store student information.

### Features
- Add new student records
- View all student records
- Search students by ID
- Update student details
- Delete student records
- Store data using SQLite database
- Simple menu-driven interface

### Technologies Used
- Python
- SQLite
- SQL

### How to Run
1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command in the terminal:

```bash
python student_management.py
```

### Database
The SQLite database file `students.db` is created automatically when the program runs.
